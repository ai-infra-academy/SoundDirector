      Use with Claude Code

      1. Get the library. Clone the repository, or copy its .claude/skills/ folder into your project. 
        git clone <this repository> SoundDirector
      2. Optional: install globally. Symlink either skill into your personal skills folder so every project can use it. 
        ln -s "$PWD/SoundDirector/.claude/skills/sound-effects" ~/.claude/skills/sound-effects
ln -s "$PWD/SoundDirector/.claude/skills/background-music" ~/.claude/skills/background-music
      3. Ask in plain words. Claude Code finds the skills and searches by description. 
        "Add a soft click to each bullet reveal on these slides"
"Find calm instrumental music for this 60-second tutorial"
      4. Or search yourself, with Python 3.9+ and nothing else: 
        python3 scripts/search_assets.py --skill sound-effects --query "gentle whoosh" --limit 5

      Slide work uses sound effects only. Music is added when you ask for it.
